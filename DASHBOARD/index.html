About SAINT BOT ROOM

Standalone MT5 scanner and terminal-control application.

SAINT BOT ROOM

This room monitors registered MT5 accounts and sends START BOT, STOP BOT, REFRESH and CLOSE ALL commands to the SAINT MT5 Controller EA.

CLOSE ALL POSITIONS is a real trading action. Use it only when you intentionally want every open position on the selected account closed.

Firebase, Firestore and SAINT ADMIN are not required for this control room.
